StayFinder is a property rental and booking web application that connects property owners (Producers) with customers (Consumers). Consumers can explore properties, search by location, view property details, save favorites, and book stays. Producers can register, list their properties, manage their listings, and view customer bookings.
<br>
The project uses HTML, CSS, and JavaScript for the frontend and C++ for the backend, with data structures such as Hash Maps, Queues, Stacks, and Heaps to manage application operations. It uses text files for data persistence instead of a traditional database.
